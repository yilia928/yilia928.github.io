流转规则：
  • 公海线索可被任何销售领取，领取后重新进入「跟进中」，原负责人收到通知；
  • 「无效」为终态，需选择原因（空号/非目标客户/竞对已合作等），不可逆；
  • 转化动作原子性：客户 + 商机 + 转化记录一次事务生成，线索状态同步变更。

    需求明确
    需求确认 30%
    门禁：POC/方案评审通过
    方案报价 45%
    门禁：报价单上传
    商务谈判 75%
    签约
    赢单 → 生成合同
    任一阶段可
    输单（原因+竞对必填）
    流转规则：
  • 阶段只能前进或关单，反向回退需主管审批（如商务谈判→方案报价）；
  • 每阶段设「门禁校验」与「停留时长阈值」（商务谈判 7 天），超时自动提醒主管；
  • 输单可由主管执行「重启」回到初步接触，需补充新的推进策略；
  • 加权预测金额 = 商机金额 × 阶段赢率，随阶段变更自动重算。

  • 执行中变更走「合同变更」子流程，留痕版本对比；作废需审批并回收相关回款计划。

    智销云 CRM 管理后台

    ① 工作台

    • 销售工作台：待办 / 漏斗 / 目标完成度
    • 主管驾驶舱：团队漏斗 / 红线预警
    • 区域经营视图：汇总看板

    ② 客户管理

    • 线索：我的线索 / 线索池 / 公海 ★
    • 线索详情：跟进时间线 / 转化检查 ★
    • 客户：360° 档案 / 客户公海
    • 联系人：决策链管理

    ③ 商机与交易

    • 商机：列表 / 看板 / 详情 ★
    • 报价单：CPQ 版本管理
    • 合同：审批流 / 变更 ★
    • 回款：计划 / 登记 / 核销 ★

    ④ 数据分析

    • 销售简报：日报 / 周报自动生成
    • 漏斗分析：阶段转化率
    • 指标看板：线索转化率 / 赢单周期 / 跟进及时率
    • 自定义报表：拖拽配置

    ⑤ 系统管理

    • 组织与角色：三级角色体系 ★
    • 数据权限：本人/团队/区域 ★
    • 审批流：折扣 / 合同分档
    • 公海规则 / 回收站
    • 自定义字段
