# 作品集 · 作品一
# 跨境电商多店铺订单管理（MVP 产品设计）

> **作品定位**：从 0 到 1 的 B 端 SaaS 产品设计练习
> **我的角色**：产品负责人（独立完成需求分析、产品设计、原型、PRD）
> **一句话结论**：面向东南亚跨境电商中小卖家，用 1 个后台聚合多平台订单，解决「超卖、漏单、对账难」三大核心问题
> **状态**：MVP 阶段｜2026-09 启动

---

## 1. 需求背景

### 1.1 行业背景

- 东南亚电商市场以 Shopee、Lazada、TikTok Shop 三大平台为主，多平台开店已成为中小卖家的主流经营策略——分散风险、扩大流量入口。
- 卖家需要频繁在多个平台后台之间切换处理订单、库存与对账。行业调查显示，跨境卖家近 **30% 的人力时间**耗费在跨平台订单处理上，日单量几十单时尚可人工应付，几百单后漏单、错发、延迟发货概率显著上升 [1]。
- 市场上已存在 BigSeller（110 万+ 东南亚卖家）、薛猫助手、妙手 ERP 等工具，但中小卖家仍普遍反馈「上手复杂、核心流程不顺、服务断层」，差异化机会在于**聚焦订单处理核心链路的轻量体验** [2][3]。

### 1.2 核心矛盾（卖家视角的四大痛点根源）

| 矛盾 | 后果 |
|---|---|
| 订单分散在各平台 × 人工汇总 | 漏单、错发、延迟发货 |
| 库存跨店不同步 × 平台实时扣减 | **超卖** → 赔付、店铺扣分（多平台运营最高发风险）[4] |
| 平台规则碎片化（物流时效、面单格式各异）× 人工记忆 | 踩坑、违规处罚。如 Shopee 要求 48 小时首条物流信息、TikTok Shop 要求 72 小时发货率 ≥95% [5] |
| 平台结算口径不一 × 手动对账 | 账目不清、利润核算滞后至少 3 天 [6] |

| 维度 | 内容 |
|---|---|
| 背景 | 32 岁，深圳做跨境 3 年，夫妻两人经营 |
| 店铺 | Shopee 马来站 + Lazada 泰国站 + TikTok Shop 东南亚，共 3 店 |

| 核心诉求 | 少切换后台、少重复操作、别超卖、月底对账别崩溃 |

### 画像 B：小型团队

| 维度 | 内容 |
|---|---|

| 店铺 | 4-8 家店，跨 2-3 个国家站点 |
| 核心诉求 | 统一管理、权限分工、批量发货、库存预警 |
| 付费意愿 | 高于夫妻店，可接受 500-2000 元/月 |

## 3. 核心痛点清单（按优先级）

### P0 · 决定生死（必须解决）

1. **库存跨店不同步 → 超卖**：全渠道共享库存模式下，数据同步延迟 + 直播爆单/大促极易库存卖穿，引发超卖赔付、店铺扣分 [4]。
2. **订单分散 → 漏单、错发、延迟发货**：多后台频繁切换，人工处理增加出错概率 [1]。

### P1 · 严重影响效率

3. **手动对账**：平台结算单口径不一，账目对不上，利润核算滞后 [6]。
4. **批量发货能力弱**：单量上升后，打单、贴单、回传单号成为瓶颈 [7]。
5. **缺货无预警**：发货时才被动发现，紧急调拨、取消订单，体验与成本双输。

### P2 · 体验与深度

6. **平台规则差异靠人工记忆**：物流时效、面单格式、退货政策各异，易踩坑 [5]。
7. **售后/退款分散**：跨平台难以统一跟踪，纠纷处理被动。

## 4. 产品目标（MVP）

- **一句话定位**：东南亚跨境中小卖家的「多平台订单中控台」。
- **北极星指标**：百单订单处理耗时（分钟/百单）。
- **MVP 成功标准（预估，待上线验证）**：
  - 订单处理效率提升 **40%+**
  - 超卖率下降 **50%+**
  - 对账耗时减少 **60%+**
- **差异化定位**：区别于 BigSeller 等全功能 ERP，聚焦「订单处理核心链路」，做「轻、快、易上手」的体验。

---

## 5. 范围与边界（MVP）

### MVP 包含

| 模块 | 说明 |
|---|---|
| 订单中心 | 多平台订单聚合、筛选、批量操作、发货回传 |
| 库存管理 | 跨店库存同步、超卖预警 |
| 对账中心 | 平台结算单核对（v1 简化版） |
| 仪表盘 | 订单 / 库存 / 异常总览 |
| 店铺管理 | 多店铺授权与基础设置 |

### MVP 不做（后续迭代）

- 进销存（采购、入库、成本核算）
- 海外仓 WMS 深度集成
- 财务核算、利润报表
- 商品刊登 / 铺货（已有成熟工具，不重复造轮子）

## 6. 竞品参考（桌面调研）

| 竞品 | 特点 | 对设计的启示 |
|---|---|---|
| BigSeller | 110 万+ 东南亚卖家，免费 ERP，Shopee/TikTok 官方认证，主打防超卖 [2] | 全功能覆盖，但上手门槛高；「防超卖」是核心卖点，必须做透 |
| 薛猫助手 XM Helper | 东南亚本地化服务，续约率 95%，咨询 + 培训模式 [3] | 服务驱动型打法；本地化（多语言、本地团队）是东南亚市场的关键 |
| 妙手 ERP | 免费，支持 28+ 平台多店铺 [8] | 平台覆盖广；验证「多平台多店」是刚需 |

**差异化机会**：聚焦「订单处理核心链路」+ 极简上手体验 + 中小卖家可负担定价。
